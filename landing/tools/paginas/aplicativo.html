Sem servidor: pareamento por código

Este é o modo do site publicado. Um navegador não consegue procurar outros aparelhos sozinho, então os dois aparelhos trocam um código uma vez:

  1. Abra o aplicativo nos dois aparelhosEm Compartilhar, toque em Parear aparelho.
  2. Gere o código em um delesEscolha Gerar o meu código. O aparelho mostra um QR Code, um link e um texto.
  3. Leia no outro aparelhoAponte a câmera do celular para o QR Code (ele abre o ERASÓ já com o código) ou cole o link ou o texto em Tenho um código ou link.
  4. Devolva a respostaO segundo aparelho mostra um código de resposta. No primeiro, leia-o com Ler com a câmera ou cole o texto, e toque em Conectar.

Pronto: os dois ficam ligados e os arquivos vão direto de um para o outro, criptografados. A ligação dura enquanto as duas páginas ficarem abertas; ao fechar uma delas, é preciso parear de novo. Não há contas nem lista de aparelhos guardada.

O código contém os endereços de rede e a impressão digital da conexão. Mostre-o apenas à pessoa que vai parear e use-o uma vez. Em redes diferentes, o aparelho consulta um servidor STUN público para descobrir o próprio endereço; redes muito restritas podem exigir um servidor de retransmissão (TURN), que ainda [a definir].

Com servidor: aparelhos encontrados automaticamente

Se o aplicativo for aberto a partir de um servidor do ERASÓ, os aparelhos aparecem sozinhos: na mesma rede (modo local) ou na mesma sala com código (modo público). O servidor só apresenta os aparelhos; os arquivos continuam indo direto. É preciso o Node.js 18 ou superior:

git clone https://github.com/SLAYERDLLBR/eraso.git
cd eraso
npm start

O terminal mostra os endereços da sua rede, como http://192.168.0.12:8780/app/index.html. Abra o mesmo endereço nos dois aparelhos, no mesmo Wi-Fi. O passo a passo para hospedar o servidor está no guia de hospedagem.
